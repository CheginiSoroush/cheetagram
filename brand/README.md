# Cheetagram brand assets (v13.2.2-cheeta.6)

Flat cheetah face in the OLED amber palette, generated with AI and processed
per Android density (script: `scripts/cheeta_brand_assets.py`).

| File | Size | Usage |
|---|---|---|
| `cheeta_icon_launcher_192.png` | 192x192 | Launcher icon (xxxhdpi, legacy path) |
| `cheeta_icon_launcher_round_192.png` | 192x192 | Round launcher icon (xxxhdpi) |
| `cheeta_foreground_432.png` | 432x432 | Adaptive icon foreground (face in 66/108 safe zone) |
| `cheeta_background_432.png` | 432x432 | Adaptive icon background (pure black) |
| `cheeta_monochrome_432.png` | 432x432 | Themed / monochrome icon glyph (Android 13+) |
| `cheeta_splash_512.png` | 512x512 | Android 12+ splash art (shown on pure black) |

These copies are exported for easy download; the app actually ships the
full density set from `TMessagesProj_App/src/main/res/mipmap-*`.
